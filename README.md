# literature_search_api
### CODE FOR LITERATURE SEARCH IN PUBMED, EUROPE PMC, AND ARXIV BY API  
* Developed by Karen Gonçalves - Postdoctoral researcher / ISGLOBAL
* Last update: 21.08.2024

This Colab notebook contains the updated Python code to reproduce a literature search on PubMed, Europe PMC, and Arxiv using their APIs. In this example, the literature search focuses on 'bipolar disorders' (health outcome) and 'environmental exposures.' You can adapt the query according to your specific search needs.

The articles will be organized by title, DOI, study design, sample size, type of exposure, clinical assessment, year of publication, number of citations, and main results. Enjoy! :)
